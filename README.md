# 馬上槍試合 — オンラインタイミングゲーム

スマホ**縦画面**向けの2.5D馬上槍試合。タイミングバーで **LANCE!** を押して槍を突く。

## 遊び方

1. ルーム作成 / コードで参加
2. **READY**
3. カウントダウン後、騎士が自動で突進
4. タイミングバーの **PERFECT** で **LANCE!** をタップ
5. 勝敗 → **再戦**

## 起動

```bash
npm install
npm start
```

## デプロイ

- フロント: Vercel
- WebSocket: Render（`server.js` を再デプロイ）
