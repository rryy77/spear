# 馬上槍試合（Joust）

中世ヨーロッパの馬上槍試合を再現した、スマホ縦画面2.5Dタイミングゲーム。

## ルール

- ティルト（中央柵）を挟んで **3回突進**
- 兜3点 / 盾2点 / 胴1点 / 槍破壊+1点
- **落馬で即勝利** / 馬命中は反則

## 操作

1. **HIGH**（兜） / **MID**（盾） / **LOW**（危険）で狙い
2. タイミングバーの **PERFECT** で **LANCE!**

## オンライン

ルーム作成 → コード参加 → READY → 3突進

## 起動

```bash
npm install && npm start
```

Vercel（フロント）+ Render（WebSocket `server.js`）
